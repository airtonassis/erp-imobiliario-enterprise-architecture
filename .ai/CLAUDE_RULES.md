# Regras

Nunca criar código fora do DDD.
Nunca acessar Infrastructure pelo Domain.
Nunca criar regra de negócio em Controller.
Nunca ignorar Use Cases.
Nunca gerar código sem consultar a documentação do domínio.
Nunca criar entidades anêmicas.
Sempre utilizar Result Pattern.
Sempre respeitar Multi-Tenant.
