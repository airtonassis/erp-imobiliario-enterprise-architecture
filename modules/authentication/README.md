# Properties Module

## Objetivo

Gerenciar todo o ciclo de vida dos imóveis.

## Responsabilidades

- Cadastro de imóveis
- Fotos
- Vídeos
- Documentos
- Localização
- Geolocalização
- Características
- Status
- Proprietário
- Histórico

## Entidades

- Property
- PropertyAddress
- PropertyImage
- PropertyDocument
- PropertyFeature

## APIs

- POST /properties
- PUT /properties
- DELETE /properties
- GET /properties

## Eventos

- PropertyCreated
- PropertyUpdated
- PropertyPublished
- PropertySold
- PropertyRented
