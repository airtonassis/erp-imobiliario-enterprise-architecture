# Payments Module

## Objetivo

Centralizar todos os meios de pagamento do ERP.

## Responsabilidades

- PIX
- Boletos
- Cartão de Crédito
- Gateway de Pagamento
- Conciliação Financeira
- Estornos
- Cobranças Automáticas

## Entidades

- Payment
- Charge
- Invoice
- Transaction

## APIs

- POST /payments
- GET /payments

## Eventos

- PaymentCreated
- PaymentApproved
- PaymentCanceled
